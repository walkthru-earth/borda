# Borda | بوردة

An Egyptian component finder for makers, engineering students, and hardware builders.

[Website](https://walkthru.earth/borda) · [Source code](https://github.com/walkthru-earth/borda)

**Promise:** find components across local stores, compare recorded prices, and get back to building.

**Tagline:** قطعتك فين؟ · Find. Compare. Build.

## Identity

- Deep teal `#087f73`: PCB traces and the primary brand color.
- Copper `#D69B65`: solder pads and small highlights.
- Ivory `#F6F5EF`: backgrounds for brand graphics.
- Navy `#172b3a`: readable headings and text.
- The lowercase b mark combines a circuit board, connection traces, and solder pads.
- Arabic interface typography uses Cairo, with right-to-left layout and unchanged technical part numbers.
- Keep the tone practical and friendly. Avoid claims of live prices or guaranteed stock.

## Assets

- `frontend/static/brand/borda-logo.png`: generated bilingual logo, suitable for a social profile.
- `frontend/static/brand/borda-social.png`: generated square Arabic launch graphic.
- `frontend/static/brand/borda-mark.svg`: simplified scalable companion mark for navigation and favicon.

The PNGs were created with the built-in image generation tool. The SVG is a hand-authored simplified companion for small UI sizes. Preserve the original PNGs; do not stretch, recolor, or crop away the wordmark. The public name is Borda; the Python package and CLI remain `egmarket`.
